# 타이머 (크로스핏 타이머 + 깜짝 장난)

빌드 없는 정적 PWA. Vercel에 연결하면 바로 배포되고, 모바일 브라우저에서 "홈 화면에 추가"하면 앱처럼 사용 가능.

- **AMRAP** (총 시간, 라운드 +1/−1 카운트, 평균 페이스) / **EMOM** / **타바타** / **인터벌**
- **FOR TIME**: 스톱워치 + 타임캡 + 랩(구간) 기록
- 프리셋, ± 스테퍼 설정, 음성 안내/효과음/진동, 화면 꺼짐 방지, 운동 기록 자동 저장
- **시작을 누르면** 폭죽 + 깜짝 사진 + 효과음 (더보기에서 끄기)
- 깜짝 사진은 루트의 `prank.jpg` (교체하면 바뀜, 없으면 🤪)
